## 简介

这个仓库存储了《信号与系统中的数学》的所有代码，可以找到最新版的pdf进行下载。本书第二版初稿已发布，将会持续勘误、更新。

本书旨在对信号与系统的数学原理进行补充和深化，大部分内容取材于“傅里叶分析”课程，并且融合了一些工程上的应用，以及常微分方程、实变函数、复变函数和泛函分析等课程的初步知识。

本书给出了两种模板的版本，frame版的定理、证明等有边框，读者可根据自己的喜好进行选择。

## 特色

第一，现有教材均在数学上做了简化，而本书结合以傅里叶分析为代表的数学专业课程，补全了这些内容，以供希望深入学习信号与系统，或者数学专业的读者参考。

第二，本书补充了大量课程以外的内容，它们或为知识的数学背景，或为课内知识在类比推理下的自然延伸，或为后续课程内容的简要介绍。这些内容旨在帮助读者节省查找资料的时间，快速建立对此类内容涉及到的问题及其背景的直观认识。

第三，许多工科教材的行文逻辑都不是完整的，这或许是出于读者普遍对所讨论的问题背景有所了解。本书力求给每个问题、定义和定理给出严谨、完整的说明，还将探索定理的边界条件，减小初学者和其他专业读者的阅读障碍。

第四，国内外的信号与系统课程以及后续相关课程对于傅里叶变换的定义有所不同，一种为频率形式，另一种为角频率形式，这种定义上的不同会导致诸多公式的内核相同但形式不同。本书将在介绍傅里叶变换时同时给出两种形式的公式。我们将看到，同时给出两种傅里叶变换，不仅方便查找、对比公式，理解傅里叶变换的本质，还能在必要时转向其中一种傅里叶变换，使得讨论更加简洁明快。

## 第二版简介
- 添加了**DTFT的分布理论**（第六章第4节），这使得周期序列也能进行DTFT.

基于此研究了序列的卷积、相关和谱密度，在第二章和第六章中对正则分布 $\text{p.v.}\dfrac{1}{x}$ 做了进一步讨论，同时在第七章中给出了离散系统的时延的更直观的物理意义；

- 在第五章中，对双边拉普拉斯变换进行了更详细的讨论，这使得本书能够从复频域的角度讨论非因果的LTI
- 重新整理了第五、六、七章的结构，尤其是将第七章中的离散系统分析的讲解思路改为：概述->z变换->频响；
- 重写了第一章中实变函数的内容，仅保留必要的部分，使得基础知识更加易于理解；
- 在第一章中添加了三角多项式与切比雪夫多项式的内容，这使得三角、指数形式的傅里叶级数的互相转化更自然，且为附录中新增的Weierstrass第二逼近定理做准备

接下来，我计划将MIMO单列一章，进行更深入的讨论，同时优化章节结构，将第三章、第七章中对LTI MIMO系统的讨论移入本章；此外，因果系统以及最小相位系统都涉及到Hardy空间的理论，这部分内容可能会在一段时间后新增于附录B.
